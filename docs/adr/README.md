# Architecture Decision Records

Short documents that record an important technical decision: the context, the options considered, the choice and its consequences. One file per decision, numbered in order. Once accepted, an ADR is not edited; a later ADR supersedes it.

| ADR | Decision | Status |
|---|---|---|
| [0001](0001-backend-platform.md) | Backend platform: migrate from Appwrite to Supabase | Accepted |

**New ADR:** copy the structure of 0001 (Context, Options, Decision, Consequences), take the next number, and open a PR labelled `needs-decision` so the team can comment before it is merged.
